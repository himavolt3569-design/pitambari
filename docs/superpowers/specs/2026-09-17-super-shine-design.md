# Super Shine storefront

Build a separate Nepal storefront for Super Shine Pitambari Liquid using the supplied bottle, copper/brass scenes and comparison images. Preserve the reference app's cart, checkout, delivery, manual payments, order tracking/cancellation, localization, protected administration and partner ledger. Reference project stays untouched; no credentials or customer data are copied.

Visual direction: porcelain #ffffff, label red #9b201f, dark red #651817, brass #b48a36, pale gold #f4e6ca, ink #342622. Broad photography, a red display headline and an integrated purchase panel replace the reference's blue/aqua arch and repeated cards. Use Trebuchet MS for confident rounded display type and Arial with system Devanagari fallbacks for interface copy. No decorative gradients or perpetual motion. Buy Now is a substantial red control with visible total, bag icon, tactile pressed state, and direct checkout. Mobile receives a persistent purchase shortcut.

Superadmin owns all sizes, prices and stock. Seed no purchasable variants. Unconfigured storefront keeps the product visible, explains availability, and prevents purchase. Products editor must create arbitrary variants as well as edit them. No invented testimonials, prices, guarantees or application ratios.

Video: optional admin-controlled YouTube or direct MP4/WebM URL, title, description, poster, enabled switch. YouTube uses a validated privacy-enhanced embed loaded on click. Missing source hides video; instructions remain visible. Do not store video bytes in Firestore. Firebase deployment is separate from implementation.

Verification: existing domain tests, new video URL and catalogue readiness tests, lint, TypeScript, production build, desktop/mobile browser checks and configured purchase-flow fixture. Live Firebase actions require this site's credentials and are not asserted from local preview.
